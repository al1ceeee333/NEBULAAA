# NEBULA

Sound-reactive macOS VST3 visualizer built with JUCE.

- Black background
- Red particles (`#ED1C24`)
- Strong glow
- Invisible circular boundary
- No logo and no visible filled circle
- Universal macOS build for Apple Silicon and Intel

## Build

Open **Actions**, select **Build NEBULA for macOS**, choose **Run workflow**, and download the `NEBULA-macOS-VST3` artifact after the build succeeds.
